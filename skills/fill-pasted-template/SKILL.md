# Fill a pasted template in its own layout

Copy the user's template exactly. Keep its rows, their order, its blank rows and section headers, and its label text. Only the value cells change.

- Do not invent a column schema such as Category, Platform, Source. The first attempt in the episode did that, and the user had to paste the template again.
- Rename a copied label only where it names a different game or product. Say so in one line.
- Leave a cell blank when the project has no value. Do not guess. In the report, list the blank cells grouped by reason.
- Write the file to the scratchpad directory. Report its path and the import step, such as the top-left cell to paste at.
- Name the source file for each value in the report. Keep sources out of the sheet itself.
